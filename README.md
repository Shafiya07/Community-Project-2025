# Namma Seva

A bilingual local directory prototype that helps residents discover and contact independent skilled workers in Tumakuru, Karnataka.

## Start the project

Open a terminal in [`nammaseva/`](./nammaseva/), then follow its [setup and limitations](./nammaseva/README.md). The React app and its JSON development API run in separate terminals.

The project does not currently have a deployed public website URL. Use the local development URL described in the setup guide.
